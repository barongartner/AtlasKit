# Watches

Time-sensitive email watches. Gmail pushes new mail to the bot the moment it lands, day and night, with no bulk filter. A match starts a `[Mail watch]` turn and Atlas decides whether it's worth a text.

One watch per line under Active, written as a list item: `<match> | <label>`. The match is part of the sender's name or address; start it with `subject:` to match the subject instead. Move a line to Done with the date to stop watching.
